# Red vs Blue Cybersecurity Wargame

Educational cybersecurity wargame featuring abstract Red Team vs Blue Team tactics, strategic decision making, and automated PDF after-action reports.

## Features

- Turn-based Red Team vs Blue Team gameplay
- Tkinter graphical user interface
- Six attack tactics and six defensive countermeasures
- Budget and resource management
- Dice-based probability engine
- Automated PDF after-action reporting
- Educational cybersecurity awareness focus

## Files

- `red_vs_blue_game_v2.py` – main game application
- `red_vs_blue_demo_save.json` – example saved game
- `red_vs_blue_v2_demo_report.pdf` – sample after-action report

## Educational Scope

This project is intended for cybersecurity awareness, training, and strategic decision-making. All attack and defence actions are abstract game mechanics and do not model real-world attack procedures.
